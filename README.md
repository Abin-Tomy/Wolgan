# Wolgan Website

A high-fidelity, cinematic web experience for Wolgan, a leader in water treatment and mechanical solutions across Qatar, UAE, and India.

## 🚀 Technology Stack
- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: GSAP (GreenSock Animation Platform) for scroll-driven cinematic sequences.
- **Components**: Radix UI & Custom Modular UI Library.

## 📁 Architecture
The project follows a modular component structure designed for high-performance animations:
- `src/components/experience/`: Houses the complex, multi-phase cinematic journey components.
- `src/components/ui/`: Contains atomic, reusable UI elements (Typography, Buttons, Icons).
- `_archive/`: Isolated storage for legacy code and design iterations (Ignored by build process).

## 🎨 Design System
The design system is centered around a premium brand identity:
- **Primary Color**: Brand Navy (`#0A1F3C`)
- **Accent Color**: Brand Gold (`#B08D57`)
- **Atmosphere**: Deep blurs, glassmorphism, and fluid typography.
